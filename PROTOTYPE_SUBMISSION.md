Space Shooter — Prototype Phase
Short description
My prototype is a single-player, Space Invaders–style browser game with one playable level. Players move horizontally, shoot enemies and avoid enemy fire. It includes scoring, lives, collision detection, hit feedback, victory and game-over states. Restarting resets the game. AI supports development; the game itself runs without an AI model.
Technologies
• Game: HTML, CSS, vanilla JavaScript and HTML Canvas.
• Development: VS Code, Git and GitHub.
• AI assistance: Codex for implementation and documentation; Perplexity for planning, explanations and review; local Gemma 4 E4B through LM Studio for a focused restart-code review. Findings were evaluated before acceptance.
• Video: ElevenLabs narration combined with actual gameplay footage using iMovie.
