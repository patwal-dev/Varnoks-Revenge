# Prototype-Phase Forum Submission Draft

## 1. Short description

My prototype is a single-player, Space Invaders–style browser game with one playable level. The player moves left and right, shoots enemies and avoids enemy fire. The game tracks score and lives and includes collisions, hit feedback, victory and game-over states. The player can restart after winning or losing, which resets the score, lives, player position, enemies and projectiles. AI tools support the development process; the game itself does not require an AI model to run.

## 2. Technologies

**Game technologies:** The prototype uses HTML, CSS and vanilla JavaScript, with HTML Canvas for rendering the game. It runs in a desktop browser without a backend, runtime AI model or player API key.

**AI development and review tools:** Development is carried out in VS Code, with Git and GitHub for version control and documentation. Codex assists with implementation and documentation, while Perplexity supports planning, explanations and review. Gemma 4 E4B, running locally through LM Studio, was used for a focused review of restart-related code. Its findings were evaluated before being accepted; it was not used to implement the prototype.

**Demonstration production tools:** ElevenLabs generated the demonstration narration. iMovie was used to combine it with actual gameplay footage.
